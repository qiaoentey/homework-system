# 洗澡资料与取消“回”点名设计

## 目标

- 从学生点名按钮中移除“回”，并拒绝新的 `home` 点名写入。
- 保留数据库中已经存在的历史“回”记录，不删除旧数据。
- 在所有学生资料表单增加“洗澡”选择：`需要`、`不需要`。
- 只要老师已选择，学生名字下方显示蓝绿色标签：`洗澡 · 需要` 或 `洗澡 · 不需要`；未选择时不显示。

## 数据与界面

使用现有资料 JSON 增加字符串字段 `showerRequired`。React、Express 与 Sites Worker 使用同一个严格字段清单，新增学生、修改资料、停补和恢复学生时均保留该值。资料表单使用一个下拉选项，不增加额外操作。

点名栏仍保留“冲”作为当天洗澡点名记录；“洗澡”资料表示该学生的一般需要，两者用途不同。

## 验证

自动检查按钮顺序、后端拒绝新 `home` 记录、`需要/不需要` 保存、学生标签显示、旧资料缺少字段时的兼容，以及桌面和手机版完整流程。
