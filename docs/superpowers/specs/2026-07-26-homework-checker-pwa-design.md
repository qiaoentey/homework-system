# 安亲班功课检查 PWA 设计规格

日期：2026-07-26  
状态：用户已确认

## 1. 目标

为安亲班老师提供一个完全免费、无需登录、Android 与 iPhone 都能打开的手机网页 App。网站把现有的一至三年级全科活动本答案入口与一至六年级数学拍照检查整合在同一个地方。

老师既可直接按年级和科目打开活动本答案，也可拍摄或上传学生数学作业，让系统在手机本机分析照片并直接在原图圈出疑似错误。系统优先减少老师查找答案及逐题重新计算的时间，但不取代老师的最终判断。

## 2. 不可变约束

- 不收取订阅费或按次扫描费用。
- 不依赖 Mac、电脑或其他本地主机。
- 不要求老师注册或登录。
- 同一链接可在 Android 与 iPhone 浏览器使用。
- 学生照片不上传到服务器。
- 不长期保存学生照片或分析结果。
- 老师可把网页添加到手机主画面，以接近原生 App 的方式打开。
- 一至三年级全科活动本答案与数学拍照检查必须位于同一个网站。

## 3. 第一阶段范围

### 3.1 活动本答案资料库

整合已经生成的 12 份手机阅读版 PDF：

- 一年级：华文、国语、数学、科学
- 二年级：华文、国语、数学、科学
- 三年级：华文、国语、数学、科学

每份 PDF 保留上册、下册、完整版或快速版答案影片入口。网站同时提供：

- 年级筛选
- 科目筛选
- 直接打开 PDF
- 直接打开对应答案影片
- 下载 PDF 到手机

现有 PDF 是答案影片导航索引，不复制 YouTube 影片或出版社教材内容。若原发布者删除或更改影片，网站应显示清楚的链接失效提示，而不是提供未经授权的镜像内容。

### 3.2 数学拍照检查支持内容

- 加法、减法、乘法、除法
- 混合运算及括号
- 横式与可可靠识别的竖式最终答案
- 分数、小数与百分比
- 简单方程
- 常见长度、重量、容量、时间及货币换算
- 正方形与长方形的周长和面积
- 应用题中学生已经写出的算式、计算结果和单位

### 3.3 暂不承诺

- 准确理解所有应用题题意
- 可靠识别非常潦草、重叠或被涂改遮挡的字迹
- 判断未写出算式的复杂应用题答案
- 批改作文或非数学科目
- 自动从 YouTube 影片提取标准答案
- 多位老师共享历史记录

这些情况必须保守处理，标示为“需要老师确认”，不能猜测式判错。

## 4. 老师使用流程

1. 老师打开一个固定链接，无需登录。
2. 首页提供两个同等清楚的主要入口：
   - `快速查答案`
   - `拍照检查数学`
3. 选择 `快速查答案` 后：
   - 选择一年级、二年级或三年级
   - 选择华文、国语、数学或科学
   - 打开或下载对应 PDF，也可直接进入答案影片
4. 选择 `拍照检查数学` 后：
   - 直接拍照
   - 或从相册选择照片
5. 系统在本机自动进行裁边、方向校正、对比度增强和阴影减弱。
6. 系统自动识别题目区域、题号、算式、答案和单位，不要求老师选择题型。
7. 数学引擎重新计算能够明确解析的题目。
8. 系统把标记画回原照片：
   - 红框：高信心错误
   - 橙框：识别或判断不确定，需要老师确认
   - 绿色标记：检查通过；默认弱化显示，避免画面过度拥挤
9. 老师点击标记查看识别内容、错误原因和建议答案。
10. 老师可以取消误判、恢复标记或修改系统读错的数字。
11. 老师下载带批改标记的图片，或直接检查下一页。
12. 离开页面或清除当前任务后，原照片和结果从当前浏览器会话释放。

## 5. 技术架构

### 5.1 PWA 外壳

- 响应式单页应用，触控目标适合手机。
- 首页、答案资料库和数学检查器采用清楚分区，但共享同一站点导航。
- 使用 Web App Manifest 支持“添加到主画面”。
- 使用 Service Worker 缓存静态资源和 OCR 模型，使首次加载完成后可离线使用主要功能。
- 不建立用户账户、数据库或照片上传接口。

### 5.2 答案资料库

- 12 份 PDF 作为站点静态资源随版本发布。
- 年级、科目、PDF 路径及答案影片链接存放在一个可验证的结构化资料清单。
- 卡片组件只负责展示资料；筛选逻辑与资料清单分离。
- PDF 在手机浏览器可直接预览，并提供明确下载按钮。
- 答案资料库可在 Service Worker 缓存后离线打开；YouTube 影片仍需要联网。
- 新增年级或科目时只更新资料清单和静态文件，不修改筛选器核心逻辑。

### 5.3 图像处理

所有处理在浏览器内进行：

- 压缩超大照片，保留足够识别分辨率
- 检测纸张边缘并裁切
- 透视和旋转校正
- 灰阶、局部对比度增强和简单去噪
- 保留原图坐标与处理图坐标之间的转换关系

坐标转换必须可逆，确保识别框能够准确画回原照片。

### 5.4 OCR

- 使用可在浏览器运行的免费开源 OCR。
- 第一阶段加载数字、拉丁字符、数学符号、简体／繁体中文所需模型。
- OCR 输出必须包含文字、边界框和信心分数。
- 页面自动分区后分别识别，以降低整页密集内容造成的错误。
- 低信心字符不得直接用于红框判错。

### 5.5 题目分割与解析

分割器综合使用：

- 题号模式
- 行距与空白区域
- 横线、方框、等号和运算符
- OCR 边界框的空间关系

解析器将可识别内容转换为受控数学表达式，不执行任意代码。每一题保留：

- 原始识别文字
- 标准化表达式
- 学生答案
- 单位
- 原图边界框
- OCR 信心
- 解析信心

### 5.6 数学检查引擎

- 使用确定性数学计算，不使用生成式 AI。
- 分数使用精确有理数计算，避免浮点误差。
- 小数与货币采用明确精度和舍入规则。
- 单位换算使用白名单换算表。
- 表达式解析使用允许列表，禁止 `eval`。
- 每种题型独立实现解析器与验证器，避免一个大型模块处理所有逻辑。

应用题第一阶段只检查学生已经写出的算式、计算结果及单位。系统可以使用关键词辅助判断单位或运算，但关键词不足时只能标橙框。

### 5.7 标注层

- 原照片保持不变，标注绘制在独立 Canvas 图层。
- 标注记录包含题目 ID、边界框、严重程度、说明及建议答案。
- 老师的取消、恢复和数字修正只保存在当前会话。
- 下载时把原图与当前标注合成为新图片。

## 6. 信心与判错规则

红框必须同时满足：

- 题目区域定位可靠
- 关键数字和运算符 OCR 信心达到门槛
- 表达式可无歧义解析
- 数学引擎能够给出唯一结果
- 学生答案与唯一结果不一致

任一条件不足时使用橙框或不判断。系统不得把 OCR 读错造成的差异直接标成红框。

老师修正一个读错数字后，系统只重新计算受影响题目，不重新处理整页。

## 7. 错误处理

- 照片模糊：显示拍摄建议，并允许继续以低信心模式分析。
- 页面太暗或有严重阴影：展示增强预览，允许老师重拍。
- OCR 模型尚未下载：显示明确进度；下载失败时提供重试。
- 浏览器内存不足：自动降低图片分辨率并重新处理一次。
- 无法分题：让老师在照片上框选一个题目后单题检查。
- 无法解析：显示识别文字和“需要老师确认”，不生成答案。
- 离线且模型未缓存：说明首次使用需要联网下载模型。

## 8. 隐私与安全

- 图片不得通过网络请求、日志、分析工具或错误报告上传。
- 默认不启用第三方行为追踪。
- 不收集学生姓名、班级、老师身份或设备标识。
- 图片对象、Canvas 和临时结果在任务结束后主动释放。
- 下载文件由老师主动触发。
- 页面明确显示“照片只在此手机处理”。

## 9. 性能目标

在近五年内的中端手机上：

- 首次模型下载后，单页基础计算作业应在合理等待时间内完成。
- 分析过程分阶段显示进度：整理照片、读取题目、重新计算、绘制结果。
- OCR 与图像处理放入 Web Worker，避免页面冻结。
- 大图先生成识别版本；下载批改图时再使用较高分辨率原图合成。

具体秒数不在未经真实设备测试前承诺。

## 10. 验证与测试

### 10.1 自动测试

- 答案资料清单包含预期的 3 个年级、4 个科目和 12 份 PDF
- 每个 PDF 路径存在且可打开
- 年级与科目筛选结果正确
- PDF 下载与答案影片链接目标正确
- 每种数学题型的正确、错误、边界及非法输入
- 分数、小数、货币和单位换算精度
- 表达式安全解析
- OCR 坐标映射到原图
- 红框信心门槛
- 老师修正数字后的局部重算

### 10.2 样本测试

建立不含真实学生身份的测试集：

- 一至六年级
- 印刷练习纸与簿子抄题
- 不同手机、光线、角度和字迹
- 正确答案、典型粗心错误和无法判断样本

首要质量指标是红框准确率。宁可漏掉难题并标橙框，也不能大量误判正确答案。

### 10.3 设备测试

- iPhone Safari
- Android Chrome
- 添加到主画面后的独立显示模式
- 首次联网、模型缓存及离线重开
- 活动本答案筛选、PDF 预览、PDF 下载和影片跳转
- 相机拍照、相册选择和批改图下载

## 11. 发布方式

- 部署为免费的静态 PWA。
- 以一个固定 HTTPS 链接供全部老师使用。
- 同一个发布版本包含网站程序、12 份 PDF 及答案资料清单。
- 不使用收费数据库、登录服务或推理 API。
- 发布前检查托管平台的免费额度；站点保持纯静态，使迁移到其他免费静态托管服务容易。

## 12. 成功标准

第一版成功的定义：

- 老师无需说明即可在手机完成拍照、查看圈错和下载结果。
- 老师能从同一首页在三次点击内打开指定年级与科目的答案 PDF。
- 12 份一至三年级全科活动本答案 PDF 均可在手机打开或下载。
- Android 与 iPhone 使用同一链接。
- 所有照片处理留在设备。
- 已支持题型的确定性计算结果正确。
- 系统在信心不足时保守标橙框，不伪装成确定答案。
- 对常见基础计算粗心错误能实质减少老师重新计算的数量。
