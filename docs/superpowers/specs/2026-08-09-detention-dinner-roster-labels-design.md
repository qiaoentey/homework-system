# 留堂与晚餐名单标签设计

## 问题与目标

留堂选择已经保存在 `profile.detentionType`，但名单标签没有读取这个字段，所以学生名字下方不会显示。晚餐标签只在 `dinnerRequired` 恰好为`需要`时显示，导致只有星期晚餐资料的旧记录被漏掉。

## 显示规则

- 有留堂资料时，在学生名字下方显示紫色`堂`标签。
- 标签文字为`留堂事项 · ...`，多项依固定顺序显示：听写留堂、功课留堂、不可以留堂。
- 兼容旧的单项值和新的 `|` 分隔多项值。
- `dinnerRequired` 为`需要`，或任一星期为`小`、`大`、旧值`需要`时，显示红色`餐`标签。
- 晚餐标签标题改为`需要晚餐`，并继续显示星期与大/小份；只有总开关而没有星期资料时仍显示`需要晚餐`。
- 不显示`不需要`的星期。

## 数据与验证

沿用现有 profile JSON，不增加或迁移字段。用名单组件测试复现留堂缺失和旧晚餐资料漏显，再运行完整资料、Worker、电脑和手机测试。
