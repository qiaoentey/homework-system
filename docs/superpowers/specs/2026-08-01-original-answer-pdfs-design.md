# 原创活动本答案 PDF 设计规格

日期：2026-08-01  
状态：待用户书面审核  
适用网站：安亲班功课检查系统

## 1. 目标

把网站目前的 12 份“答案影片索引 PDF”替换成真正包含答案内容的本地 PDF。老师选择年级与科目后，应能直接打开或下载答案参考，不必先跳转 YouTube。

本阶段涵盖一年级至三年级，以及现有播放清单已编目的四个科目：华文、国语、数学和科学。每个年级、每个科目各一份 PDF，共 12 份。

## 2. 版权与内容边界

- YouTube 影片由第三方 Mmm Doodly 发布，仅作为公开核对来源。
- 只允许在官方 YouTube 播放器中临时查看画面，或由浏览器产生不落盘的临时视觉帧供人工核对；不得下载影片、把画面保存成文件、提交仓库、放进 PDF 或重新发布，也不得提取或保存声音、缩图或教材页面。
- PDF 使用自行整理的文字、表格和原创说明；不复制影片里的整段范文或长篇文字。
- 数字答案、页码、题号、单元名称和客观事实可以用于建立查找索引。
- 作文、开放题和存在多种正确表达的题目，不复制第三方范文；改为提供原创检查重点、评分提示和简短原创参考表达。
- 每份 PDF 标示“老师检查参考，非出版社官方答案”。

## 3. 输出文件

固定输出路径为 `homework-checker/public/pdf/`，文件名称统一为：

```text
1年级_华文_活动本答案参考.pdf
1年级_国语_活动本答案参考.pdf
1年级_数学_活动本答案参考.pdf
1年级_科学_活动本答案参考.pdf
2年级_华文_活动本答案参考.pdf
2年级_国语_活动本答案参考.pdf
2年级_数学_活动本答案参考.pdf
2年级_科学_活动本答案参考.pdf
3年级_华文_活动本答案参考.pdf
3年级_国语_活动本答案参考.pdf
3年级_数学_活动本答案参考.pdf
3年级_科学_活动本答案参考.pdf
```

旧的 `*_活动本答案影片索引.pdf` 文件会在新文件验证通过后从网站构建中移除。

## 4. PDF 内容结构

每份 PDF 使用适合手机阅读的 A5 直向版面，并采用相同结构：

1. 封面：年级、科目、上下册覆盖范围、版本日期和免责声明。
2. 快速目录：按上册/下册、单元和页码分组。
3. 答案表：每行至少包含册别、页码或可识别位置、题号、参考答案和检查提示。
4. 待人工判断项目：作文、画图、实验观察或题目不清时，使用橙色“老师复核”标记，不能伪造唯一答案。
5. 来源说明：列出用于核对的播放清单和影片标题链接，仅作为补充讲解，不作为 PDF 主体。

科目规则：

- 数学：提供最终答案；需要步骤的题目增加一至三行原创计算提示；应用题标示算式与单位。
- 科学：提供关键词答案，并列出可接受的同义表达；实验或观察题标示判断条件。
- 华文与国语：客观题列答案；造句、理解和开放题列关键点与可接受范围。
- 作文：只提供原创检查清单、结构建议和短句示例，不提供复制自影片的完整范文。

## 5. 答案资料模型

答案内容保存在可审查的结构化资料文件中，再由生成器建立 PDF。每个答案项目包含：

```text
grade, subject, volume, unit, page, question,
answer, checking_note, confidence, source_video_id, source_timecode
```

`confidence` 只能是：

- `verified`：题目位置和答案均已人工核对；
- `review`：题目开放、画面不清或不能确定唯一答案，必须由老师复核。

任何缺少页码/可识别位置、答案或核对状态的项目都不能悄悄进入正式 PDF。

## 6. 网站行为

- 卡片主按钮改为“打开答案 PDF”和“下载答案 PDF”。
- 影片区域明确命名为“补充讲解影片”，视觉优先级低于 PDF。
- 页面说明改为“PDF 内含答案参考；影片仅供补充讲解”。
- 所有 PDF 使用相对路径，继续支持 GitHub Pages 子路径和 PWA 离线缓存。
- 不增加登入、付费服务、服务器或云端储存。

## 7. 错误处理与诚实边界

- 若公开影片下架，已核对的原创答案仍保留；来源状态另行标记，不把 PDF 变回影片索引。
- 若无法可靠识别某题，PDF 显示“老师复核”，不能猜答案。
- 若某册内容尚未完成，网站不得把空白、目录或链接页标示为“答案 PDF”；该资源显示“整理中”。
- 构建时发现 PDF 数量、路径或内容不符合规格，应直接失败，阻止发布。

## 8. 测试与验收

发布前必须同时满足：

1. 正式目录恰好包含 12 份新命名 PDF，不包含旧的“影片索引”PDF。
2. 每份文件以 `%PDF-` 开头、可正常解析、至少包含封面与答案页。
3. PDF 提取文字必须包含年级、科目、“答案参考”和至少一个结构化答案项目；不能只包含 YouTube 链接或使用说明。
4. 12 份 PDF 均经过 PNG 渲染与人工视觉检查，确认无乱码、裁切、重叠、黑块或不可读字体。
5. 网站按钮指向新 PDF；单元测试、构建测试、根路径 E2E 和 GitHub Pages 子路径 E2E 全部通过。
6. 手机上能打开、下载和离线重新打开至少一份数学 PDF 与一份语言 PDF。
7. 公开部署的 PDF 哈希与本地已验证构建一致。

## 9. 不在本阶段范围

- 不复制或重新发布第三方影片截图。
- 不把临时浏览器视觉帧保存在磁盘、Git、报告或最终成品中。
- 不宣称这些文件是出版社官方答案。
- 不把一至三年级答案自动扩展为四至六年级答案。
- 不改变现有一至六年级数学 OCR 检查范围。
- 不自动评分作文，也不把开放题误判成唯一答案。
