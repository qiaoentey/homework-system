# 点名页面今天日期显示设计

## 目标

老师进入任何分院的点名班级后，都能立即确认当前点名日期，减少跨日或未刷新页面时点错日期的风险。

## 界面

- 日期显示在班级名称正下方、学生人数说明上方。
- 内容格式为：`今天 · 2026年8月10日 · 星期一`。
- 使用现有蓝色品牌色的小标签样式；电脑和手机采用相同信息顺序，不占用搜索框空间。
- 使用语义化 `time` 元素，并保留 `YYYY-MM-DD` 机器可读日期。

## 数据与行为

- 日期继续使用点名页面现有的本地日期参数，不新增服务器请求或数据库字段。
- 正式页面未指定日期时，以设备所在时区的当天日期为准。
- 测试可传入固定日期，验证中文年月日及星期显示，避免依赖测试当天。

## 验证

- 组件测试确认固定日期显示为正确中文格式。
- 现有点名、学生资料、历史记录与 Dashboard 测试保持通过。
- 完成生产构建和 Sites 发布检查。
